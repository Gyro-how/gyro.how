title: "Fairness & matchmaking"
---

In the Cross-Platform Multiplayer world: Input Fairness is crucial to ensure a balanced and enjoyable experience for all players. Unfortuantely, every game's methods of Input Matchmaking will differ. 

Typically, matchmaking pools will group players based on Input Method of choice. **Controllers** or **Keyboard/Mouse**. However, both Gyro and Mixed Inputs methods are neglected. A Controller-only matchmaking pool will include players who have enable Gyro Aiming will be matched against Joystick Camera users. Despite the game's Aim Assist system, they may feel at a disadvantage against a "Mouse" user who snuck into a Controller-only pool.This can create an uneven playing field and negatively impact the overall fairness.

At worst, it can result in false bans due to the game's Anti-Cheat systems perceived as unfair/cheating behavior, even when the player is not actually cheating.

To prevent scenarios, we have a few suggestions.

## Suggestions for Fair Matchmaking

### Input Badge symbol
Most matchmaking systems will showcase the player's Input icon badge indicating the preferred Input method they're using. But it may not indicate if the player is using Gyro or Mixed Inputs within that Input method.

We suggest adding additional icons badges to represent Gyro and Mixed Inputs, so players can quickly identify the input methods of their opponents.

that way, Gyro and Mixed Input icons will be shown next to the Player's Input method alongside Controller and Keyboard/Mouse.
This also assists the game's Anti-Cheat system in accurately identifying legitimate input methods and reducing false positives for cheating behavior.

### Separate Matchmaking Pools (Platform/Input-based Matchmaking)

For games that uses Input-based or Platform-based Matchmaking: We recommend allowing Gyro and Mixed Input players to select their preferred matchmaking pools. 

There can be two types of Matchmaking Pools that Gyro and/or Mixed Input players can join: the **Mouse Matchmaking Pool** and the **Controller Matchmaking Pool**.

  * Mouse

### Discourage Aim Assist usage

We strongly recommend disabling Aim Assist when using either Gyro Aiming or Mixed Inputs to ensure fair gameplay and prevent unintended advantages. The **Gyro is meant to function like a Mouse**, applying Aim Assist into a precision-like aiming scheme can interfere player control.

For more details, refer to [Aim Assist page](../multiplayer/aim-assist/).
